# 液体物理パーティクルシミュレーション

Canvas上でマウスで液体パーティクルを注いだり混ぜたりできるインタラクティブ流体シミュレーション。

## 概要

Canvas全面にパーティクル300個（デフォルト）を配置。重力・衝突・境界反射の簡易物理演算をリアルタイムで実行。マウスドラッグで引き寄せ/斥力モードの力場をパーティクルに付与。クリックで新規パーティクルを生成する。

## 機能

- **引き寄せモード**: マウスカーソル周辺80px範囲のパーティクルを引き寄せる
- **斥力モード**: マウスカーソル周辺80px範囲のパーティクルを弾き飛ばす
- **色選択**: 水色・赤・緑の3色（新規生成パーティクルに適用）
- **重力スライダー**: 重力強度を0〜0.8で調整
- **パーティクル数スライダー**: 50〜500個でリアルタイム増減
- **リセット**: パーティクルを初期配置に戻す
- **一時停止/再開**: シミュレーションを一時停止
- タッチ操作対応（スマートフォン・タブレット）

## 物理エンジン仕様

- 重力加速度・速度ダンピング・最高速度制限
- 空間ハッシュ（バケツサイズ20px）による近似O(n)衝突検出
- 弾性衝突（反発係数0.7）による速度交換
- 境界壁での反射（底面は強いダンピング）
- requestAnimationFrame 60fps

## 技術仕様

- バニラJS + Canvas 2D API
- レスポンシブキャンバス（ウィンドウサイズに自動追従）
- ラジアルグラデーションによる液体感の表現
- FPSカウンター表示
